이서의 한글 ABC 마법 놀이터 - 첫 번째 PWA 버전

[노트북에서 테스트]
1. 이 폴더에서 PowerShell 열기
2. python -m http.server 8000
3. 브라우저에서 http://localhost:8000 열기

[아이폰에 설치]
이 폴더 전체를 HTTPS 정적 웹 호스팅(GitHub Pages 등)에 업로드합니다.
아이폰 Safari에서 배포된 https 주소를 연 뒤 공유 > 홈 화면에 추가.
최초 온라인으로 앱 파일을 로드해야 오프라인 캐시가 생성됩니다.
아이폰에서 비행기 모드로 테스트하세요. iOS 저장공간 정리 등에 따라 캐시가 지워질 수 있습니다.

[목소리]
현재는 기기 기본 음성 합성으로, 귀여운 녹음 음성은 아직 포함되어 있지 않습니다.
정확한 녹음 파일을 추가하려면 audio/ko/기역.mp3 등, audio/en/A.mp3 등으로 넣고
sw.js의 FILES 배열에 각 파일 경로를 추가해야 오프라인 재생됩니다.

이 버전은 HTML/CSS/JS 기반으로 Streamlit과 별개입니다.
