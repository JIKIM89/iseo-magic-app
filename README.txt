이서의 한글 ABC 마법 놀이터 — v2

수정 내용
- 없는 MP3 파일을 호출하던 오류 제거
- 글자를 누르면 오프라인에서도 재생되는 짧은 마법 효과음 추가
- 글자 발음은 여전히 iOS 내장 TTS를 사용하며, 홈 화면 웹앱에서는 작동하지 않을 수 있음
- 캐시 버전 v2 및 네트워크 우선 업데이트 방식 적용

GitHub 업데이트 방법
1. 압축을 풀고 iseo_magic_pwa_v2 폴더 안의 파일들을 확인
2. GitHub 저장소 iseo-magic-app > Add file > Upload files
3. 이 폴더 안의 파일 전체를 업로드(폴더 자체나 ZIP을 업로드하지 말 것)
4. 동일 파일을 덮어쓰는 변경사항을 Commit changes
5. Pages 배포 후 아이폰 홈 화면 앱을 완전히 종료하고 재실행

중요: 진짜 한국어/영어 발음이 오프라인에서 확실히 들리게 하려면 녹음된 음성 파일이 필요합니다.
현재 ZIP에는 녹음 음성 파일이 들어 있지 않습니다.
